# Zara Sales Analysis Project

This project analyzes Zara sales data, including:

- Cleaning and preparation of the raw dataset
- Exploratory Data Analysis (EDA) focusing on sales volume, revenue distribution, product categories, and customer sections
- Key insights into top-performing products and category trends

## Contents

- `Zara_sales_cleaning.ipynb`: Notebook for data cleaning and preparation
- `Zara_sales_EDA.ipynb`: Notebook for exploratory data analysis

## Tools Used

- Python (Pandas, Matplotlib, Seaborn, Plotly)
- Jupyter Notebook

## Goal

To understand Zara's sales dynamics and identify key factors driving performance.
